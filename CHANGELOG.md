## [0.1.0] - 2026-11-18

### Added

- A Codex marketplace package for FigCraft, installable in Desktop and CLI as `figcraft@figcraft-skills`.
- Five skills for document management, screen layout, design systems, interactive prototypes, and developer handoff and export.
- A bundled `figcraft-headless` MCP configuration that launches the local FigCraft CLI over stdio.
- Installation and troubleshooting instructions for the bundled server and custom connections, including file access roots and attachment to a running FigCraft window.

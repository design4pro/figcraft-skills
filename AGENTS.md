# Repository instructions

## Versioning and changelog

- Record user-facing changes under `Unreleased` in [CHANGELOG.md](CHANGELOG.md) as part of the change.
- For each release, choose the next version according to Semantic Versioning and set it in `plugins/figcraft/plugin.json`. Move the pending changelog entries into a dated section for that version and tag the release commit with the same version prefixed by `v`.
